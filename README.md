# GPU リモートサーバー予約アプリ

- **フレームワーク**: Python + Streamlit + SQLite
- **機能**
  - 名前・用途・必要メモリ(GB)で予約を登録
  - 同じ時間帯に複数人の予約を許可
  - 30分（変更可）粒度で時間帯ごとの**合計メモリ量**を集計
  - 合計が既定の上限（デフォルト: 24GB）を超える時間帯を**可視化**（⚠️表示）
  - 現在時点の合計メモリも表示（`st.metric`）
  - 予約のエクスポート（CSV）と個別削除

## 使い方

```bash
pip install -r requirements.txt
streamlit run app.py
```

- 初回起動時に `reservations.db` を自動生成します（同ディレクトリ）。
- サイドバーで上限メモリ（例: 24GB）と集計粒度（15/30/60分）を設定できます。
- 「状況を確認」タブに**各時間帯の合計メモリ量**と**超過の有無**が表示されます。

## メモ

- タイムゾーンは `Asia/Tokyo` 固定です。
- SQLite は軽量ですが、高頻度書き込みが集中するとロックすることがあります。より大規模運用では PostgreSQL 等への置き換えを検討してください。
